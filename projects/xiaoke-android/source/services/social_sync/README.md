# 小克密文经历接收端

这是可选的单主人同步服务，不是 QQ 登录客户端或模型中转。Python 3.10+ 标准库即可运行；没有新增服务框架。Android 原有 API 陪聊不经过它，关闭电脑只会延后经历补传。

源码：`server.py`；回环 HTTP／SQLite 验证：

```bash
python3 -m unittest discover -s services/social_sync -v
```

由部署者在私有运行环境设置随机 `XIAOKE_SYNC_TOKEN`，提供仓库外的数据库路径：

```bash
python3 services/social_sync/server.py --database /private/path/xiaoke-events.db
```

默认仅监听 `127.0.0.1:8767`。生产配对需部署者自行配置 HTTPS 反向代理、私有访问与进程管理。本轮没有部署到用户电脑、公开监听或创建账户。手机拒绝明文 HTTP 与带凭据查询参数的地址。

手机与受信设备共享独立的 32 字节随机密钥，Base64 编码后在手机“经历同步”输入；它只在手机的 Keystore 加密槽保存，不发给服务端、不写 Git。认证口令与内容加密密钥用途不同。当前服务只保存 `id/sources/ciphertext/digest`；会话范围、正文、人物等在 AES-GCM 密文内，来源索引只含 SHA-256。服务器拥有元数据和删除权，不能解密或伪造可通过认证的正文；这不防止服务器丢弃数据或拒绝服务。

协议 `POST /v1/sync`，Bearer 认证，版本 1：

```json
{"version":1,"vault":"32位十六进制命名空间","device":"设备随机ID","cursor":0,"generation":0,"events":[],"deletions":[]}
```

客户端先发送空事件批次读取删除栅栏，应用删除后再发至多 16 个密文事件。响应含 `ackIds/ackDeletions/generation/cursor/events/deletions/needsPull`。SQLite 事务提交后响应才确认；同 ID 不同密文拒绝覆盖，重复同密文返回同一确认。客户端持久保存首次加密结果，断网重试不会随机重加密后形成冲突。

删除按不含正文的来源哈希传播并级联删除派生事件。过时代际上传不会入库；接收端处理删除后再提供下载页。被删除的离线旧数据不能通过补同步重建。客户端拉回事件仅记入事件账本，不运行旧请求、旧任务或旧授权。

限制：面向轻量个人使用；无多人账户系统、反垃圾系统或高可用集群。Android 后台受系统与前台服务生命周期限制；联网恢复触发和一分钟退避只在应用进程存活时工作，不能保证锁屏全天在线。密钥遗失无法恢复密文；不同密钥形成不同命名空间。本轮同步不自动传原图或素材文件，备份只包含素材索引，迁移后需重新导入原文件。受控副本删除不能收回外部已发布内容、他人转存或仍可解密的旧备份。
