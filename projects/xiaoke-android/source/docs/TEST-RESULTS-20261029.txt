Android 16 原生运行
- Google 官方模拟器 37.2.12、Platform-Tools 37.0.1、API 36 AOSP x86_64 revision 2，来源 / 摘要记录在证据包。
- 当前云环境无 /dev/kvm，采用纯软件仿真；不更改宿主安全挂载或增加容器特权。首次系统启动很慢。
- 首次 Google APIs 镜像启动未达到可用条件，改用较轻的官方 AOSP 镜像。后者已连接 ADB / API 36，系统包管理出现；在 boot_completed 之前的安装尝试明确返回 device is still booting，不能算安装成功。
- 最终结果：截至 2026-10-29 05:17 UTC，AOSP 镜像仍未完成首启。日志证明系统 Watchdog 在主线程阻塞 66 秒后终止 system_server；此时尚未安装小克。全局 watchdog_timeout_millis 已在自建测试机写入并读回 600000，额外有界窗口仍未达到 boot_completed=1。没有禁用 Watchdog，没有改变宿主安全挂载或增加容器特权。
- APK 安装未完成；CompanionPersistenceTest 的三项 Android 仪器测试没有执行，原生界面、系统视频解码、真实 Android SQLite/加密备份与浮窗运行验收均未通过本环境验证。测试代码已经编译，可在具备硬件加速的 Android 16 模拟器或用户授权设备执行。
- 此环境的失败不能用来判定小克已运行后崩溃，也不能拿构建通过来代替运行结果。测试虚拟机在收尾停止，不持续占用资源。
- AOSP 对 Watchdog 超时的定义与可配置入口：https://android.googlesource.com/platform/frameworks/base/+/refs/heads/android16-release/services/core/java/com/android/server/Watchdog.java 。本次设置仅用于临时虚拟机；不能将该环境的响应时长作为手机性能数据。
