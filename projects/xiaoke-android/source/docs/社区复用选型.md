# 懒人包社区项目选型

核对日期：2026-10-28。链接为已访问的维护者仓库；源码固定版本见 community-pins.json。这里只读检查陌生项目，没有运行它们。最近推送是维护信号，不等同于质量保证。

| 项目与链接 | 实际代码依据／许可证 | 部署差异及本项目决策 |
|---|---|---|
| [DSH Android](https://github.com/dphmoblie/deepseek-harness-android) | DeviceBridgeServer.kt、DeepSeekAccessibilityService.kt、runtime/；主项目 MIT，PRoot GPL 等另计；v0.3.0 2026-10-18 | 已固定底座。保留工作台、文件、运行时、安卓控制。独立包名签名；修复来源摘要。 |
| [Mobilerun](https://github.com/droidrun/mobilerun) | mobilerun/ 的代理、设备与配置代码；MIT；10-28 推送 | Python agent/设备连接层，不是可直接替换的原生 Android 包。参考观察、动作反馈及模型解耦；保留 DSH 已有宿主桥。商业托管服务不算本机实现。 |
| [AstrBot](https://github.com/AstrBotDevs/AstrBot) | astrbot/core/platform/sources/{aiocqhttp,qqofficial}/、platform_message_history_mgr.py、conversation_mgr.py；AGPL-3.0；10-28 | 服务端 Python。消息结构、私聊/群 scope 和角色管理是可靠参考；QQ官方 bot 与本人账号不同，不能替代安卓 UI。避免引入整套第二 harness。 |
| [MaiBot](https://github.com/Mai-with-u/MaiBot) | src/maisaka/turn_trigger/reply_likelihood.py、scheduler.py；主仓 GPL-3.0；A_memorix 自带 AGPL-3.0；10-28 | 选取有界回复概率函数的 Android 移植，注明来源和修改；不直接套用原训练权重当普适保证，主人可调阈值/冷却。暂不整套移植 Python 记忆服务。 |
| [Bilibili MCP](https://github.com/iseenope/bilibili-mcp-server) | src/api/bilibili.ts、wbi.ts、tools/video.ts、comment.ts；MIT；07-18 | Node 服务。复用公开视频 ID、字幕/视频路径与限流语义，移植到宿主；不读取平台私有 cookie，不移植风控降级逻辑。发布由原生授权及安卓 UI 执行。 |
| [mem0](https://github.com/mem0ai/mem0) | mem0/memory/main.py 的 entity scope 与增改删，mem0-ts/src/oss/src/storage/SQLiteManager.ts 的历史/消息事务；Apache-2.0；10-26 | Python/Node 库，可自托管，也有独立商业平台。本项目复用 SQLite 历史设计与实现片段并改成 Android SQLite；增加群隔离、来源、删除清理、加密备份；不默认部署向量库或开通云服务。 |
| [Google GenAI SDK](https://github.com/googleapis/js-genai) | src/models.ts 的 continuation 循环、src/types.ts；Apache-2.0；10-28 | Node/浏览器库，非安卓控制框架。作为 Gemini 协议/工具/多模态和 Argon 续写实现依据；中转能力以本机用户后续测试为准。 |
| [SillyTavern](https://github.com/SillyTavern/SillyTavern) | src/character-card-parser.js 的 chara/ccv3 PNG 元数据处理、src/endpoints/characters.js；AGPL-3.0；10-02 | Node 后端＋网页前端。角色卡格式互操作参考，人设导入不等于执行导入卡里的系统命令；不整套打包、不代写角色正文。 |
| [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) | android/SherpaOnnx/.../OnlineRecognizer.kt 与 Gradle 工程；Apache-2.0；10-28 | 有真正 Android 本地 ASR/TTS 路线。语音可选，不拖延文字/视频观察核心；需另选模型、验证模型许可证和手机资源。 |
| [NapCatQQ](https://github.com/NapNeko/NapCatQQ) | packages/napcat-onebot/action/msg/SendMsg.ts；LICENSE 为 Limited Redistribution License，非普通 MIT；10-28 | 依赖 NTQQ 的外部协议桥，不是 Android QQ UI。许可证限制商业/修改后公开等，本轮不复制、不安装、不内置。若用户以后独立部署，可评估受限消息桥接口；维护和账号限制单列。 |

首先落地的局部复用：DSH 安卓底座 → mem0 的分域持久化/历史 → MaiBot 有界群聊调度 → Bilibili MCP 内容读取 → Google 官方协议。其余作为互操作或可选扩展。每个实际复制/移植模块必须有来源、提交、许可证、修改说明与测试，不能只在文档写“参考”却没有实际代码接入。
