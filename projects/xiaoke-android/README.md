# 小克安卓助手

基于 DSH Android 的陪伴优先助手。保留原设备、终端、文件和插件能力；原生 Gemini 兼容接入、连续陪伴、独立社交通道、可追溯记忆与辅助任务在同一宿主中协作。

本分支是正在迭代的开发源码，不能把已有候选 APK 或测试数量当作新体验已经完成。没有真实模型、账号和手机验收结果。
