# 小克

住在主人安卓手机里的陪伴者，也顺手帮主人处理事务。基于 DSH Android，原有的终端、文件、插件、无障碍和 Shizuku 都保留，在此之上加了这些：

- 和主人连续聊天：长期记忆、日记、兴趣，都能查、改、删
- 悬浮球：语音或文字陪聊；陪玩游戏时平时安静、结算时搭话；可以代操作游戏；长按五秒急停
- QQ（NapCat）群聊和私聊、自己去 B站看视频；外发评论和资料入库攒成清单，等主人确认
- 主人解锁手机时，她有新鲜事才主动来聊；夜里不打扰
- 主人聊天和她的自主活动用两个独立的额度池
