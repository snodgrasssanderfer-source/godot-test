# 现状

版本 0.4.0（versionCode 4），用固定签名，带完整 PRoot/Ubuntu 运行环境的 debug 包约 312 MiB。**还没装到真机上跑过**，下面写的都是代码层面的状态。

## 已经有的
- 聊天、记忆、日记、兴趣、预算分池。主人私聊域的记忆在读取层隔离，外部会话拿不到。预算没设置时照样能和主人聊，只有自主活动会停。
- 说话方式：回复长短跟着主人走；逻辑、代码、结构完整度上坚持自己的判断，口味和审美可以被主人慢慢影响。
- 日记：随时可看；每晚 22 点后她根据当天真实发生的事写一篇，带来源。
- 悬浮球陪聊：语音和文字都行，主人上次用哪种她就用哪种回。玩游戏时安静，结算或失败才开口。主人在聊天里请她代操作就接手，触屏即静默让出。
- 长按悬浮球五秒：点击、输入（含工作台的无障碍自动化）和外发都停，对话照常；主人在私聊或语音里说“继续”就全部恢复，群里谁说都不算。
- QQ：群聊按概率和冷却接话；主人本人的 QQ 私聊直接回复。夜间安静（23:00 后锁屏，到次日首次解锁）不进群、不看视频、不主动找主人。
- B站：主人私聊或群聊里聊到的话题，她会自己去看公开视频（字幕 + 关键帧），记成她的观察并写明看了哪部分。想说点什么时顺手起草一条带时间点的评论（需已连接 B站账号）。
- 群图片：她觉得值得留的图，提议存进资料库；原图先加密暂存，放行才入库，删掉就清除。
- 待审清单：评论草稿和保存提议都在这里，三天内有效，逐条“放行 / 删掉”或全部放行，可以看图。悬浮球角标显示数量，主人回来时她顺口提一次。
- 主动分享：解锁、两小时没聊、又有新内容时发一条，每天最多两次；靠常驻服务在 App 被回收后继续工作（需开“后台常驻”）。
