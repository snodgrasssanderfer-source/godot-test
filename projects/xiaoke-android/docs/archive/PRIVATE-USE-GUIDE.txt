小克安卓助手 · 私人使用说明
日期：2026-10-29

这是基于 dphmoblie/deepseek-harness-android v0.3.0 的独立改造。
包名 io.github.dshcompanion.mobile。原 DSH 的工作台、文件、终端与设备能力保留；小克入口增加陪伴、模型、人设、记忆和独立 QQ 通道。
完整二创人设正文由你接入 Gemini 后编写。内置几何角色只是可替换的动态示意，不代表已定稿的小克形象。

一、第一次打开
1. 按安装引导填写公开地址 https://api.apikey.fan/v1beta，或你自己的 HTTPS Gemini 兼容地址。
2. 新密钥只在手机本机填写。不要沿用聊天里曝光过的密钥。安装包、源码、说明和备份均不携带你的 API 密钥。
3. 可选择 gemini-3.8-flash 或 gemini-4-argon，也可编辑实际模型 ID。两者是本项目目标配置，不代表已经实测中转的能力、费用和速度。
4. 先保留“联网”关闭，检查角色、资料与权限；你开启联网并主动发送后，才会使用自己的模型额度。
5. 需要画面观察时启用无障碍；需要浮窗时授予悬浮窗权限；语音输入单独申请麦克风。无需为了普通对话开启所有权限。

二、持续陪伴
在对话页的陪伴面板选择本次时长、方式和感知范围，点击开启。默认不观察屏幕，也不持续收音。
选择一个具体游戏或应用后，观察仅限该应用窗口；切出即挂起画面观察，超过三分钟未返回结束会话；锁屏或息屏结束感知。无障碍界面文字不等于完整游戏画面语义，系统禁止截图的画面不会绕过。
你可在对局全程文字或语音交流，主动反应不限定在结算时。陪伴/专注/静音可切换。角色浮窗可拖动，点开可聊天、打断、保存当前事件或结束。
自动回应默认八秒截止，超时丢弃，界面可调到一至三十秒。三秒响应只是目标，真实手机、中转延迟和模型思考耗时均未预先保证。
默认使用手机系统离线 ASR/TTS。系统没有离线语音时，界面会提示，可先用文字。只有你明确勾选后才允许系统语音服务联网；数据去向是手机配置的识别/声音服务，和 Gemini 中转不同。
扬声器默认半双工，播放时暂停收音，点击“打断”或“听我说一次”可停止声音。可选耳机抢话只在系统报告实际输出到耳机时启用；扬声器免按键全双工没有实现，耳机和厂商语音服务的实际表现须在手机验证。
角色动画复用 AIRI 的眼动、情绪与元音驱动。原生 TTS 使用实际合成音频的音量包络驱动开合，不伪称音素识别。用户导入的 PNG / 动作图集保存在本机，并用于主界面和游戏浮窗；可恢复内置角色删除。图集说话帧属于示意动画。

三、画面和记忆
连续观察的原始帧、识别和短期陪伴对话放在内存，不自动转成长期关系事实。点击“保存当前陪伴事件”，才把实际已回应内容和它的画面依据写入本机观察资料及事件记忆。
普通私聊有自己的持久聊天记录；模型工具提取的记忆带来源并标为待确认。主人本机、QQ 私聊和各群独立分域。群友文字和网页内容不会变成主人权限。
“记忆”页可查看、修正、删除、追溯来源，或让已配置模型整理当前范围。删除记忆也删除它的旧修订正文。
加密备份包括人格版本、长期记忆、消息、观察摘要和任务状态；不包括 API/OneBot 密钥、账号登录、原始图片视频或可继续发送的授权。恢复后联网关闭、助手暂停，需要重新确认连接。原始媒体如需另存，请保留自己的来源文件。

四、QQ：独立 NapCat 通道
常态接收和收发使用独立 NapCat，不抢你手机 QQ 的界面。手机仍负责小克的模型与记忆；NapCat 负责独立 QQ 会话。
本次只完成 NapCat v4.18.41 固定镜像的无登录本机测试，测试后停用。没有扫码、没有账号托管、没有发送消息，也没有开放公网或保证当前任务容器能长期在线。
正式使用需一个你控制的常驻主机和手机可达的 WSS 地址。部署材料在 deploy/napcat/；保留独立 token 和有效 TLS，不把 WebUI 6099 当 OneBot 3001。
在“设备 / QQ 独立通道”填写 WSS、桥端实际 QQ 数字 ID、OneBot token。连接后会先核对桥端账号，再绑定具体好友/群 ID。接收白名单、图片、自动回复分别开启。
主人 QQ 身份须绑定精确数字 ID。群会话无法因群友自称主人就访问主人的私聊记忆或安卓操作权限。
默认先人工核对草稿；如果要自动参与，明确配置该会话的模式、冷却、每小时限额与夜间规则。自己在该会话发言后有避让窗口；连接中断或提交结果不明时不会盲目重发。
真实登录、收消息、群聊、发送以及手机与桥端的同步尚需你明确授权后验收。

五、B站与真实安卓操作
可读取公开字幕，或按范围分段读取可访问的公开视频并用系统解码取关键帧；也可以从系统文件选择器导入本地视频。公开路径失败会停止，不绕过登录或访问限制。
资料明确记载字幕/画面范围和采样时间。关键帧、字幕、音轨的覆盖不同，不会仅凭标题宣称看过整段；当前公开取帧路径不自动获得音轨。
附加资料发送给模型后才产生理解与评论草稿。正式评论需要你核对账号、视频、正文和当前界面标题，再单独确认提交。界面改动、授权超时或结果未知会停下，避免发错或重复发送。
原 DSH 工作台仍可从侧栏或手机顶部入口进入。其运行时与原 agent 配置独立保留，不声称所有原 DeepSeek 工作台的第三方模型路径已自动转成小克的原生 Gemini 会话。

六、暂停、恢复和安装签名
顶部暂停会取消当前模型工作并停止桥接。后台通知和浮窗均有停止入口。Android 及手机厂商仍可能限制长期后台运行，需要按本机显示配置通知和电池策略，不能预先保证 Android 16 全天存活。
私有构建采用独立签名。若手机已安装同包名且不同签名的旧包，Android 会拒绝覆盖；不要直接卸载丢数据，先导出旧数据并核对迁移方案。后续更新须继续使用同一私有签名材料。
所有真实账号和付费 API 测试均未包含在本轮执行中；安装后的真实发送也应按你设置的会话授权进行。

七、最少手机验证步骤
1. 安装后离线打开，完成/退出引导；建立一条测试人格版本与记忆，重启检查保留。
2. 自行填写新密钥，先做一轮普通文字及一轮自己提供图片的对话，再切换模型检查人格和记忆连续。
3. 开启五分钟、无屏幕、无麦克风的陪伴，核对浮窗、暂停、结束；再分别授权麦克风和某个应用画面。
4. 切出选定应用、锁屏，确认感知停止；未点保存的自动画面不应出现在长期资料或备份。
5. 选一段有明确内容的本地视频验证取帧范围与分析依据。暂不发布评论。
6. 只有在常驻 NapCat 主机、真实账号和发送范围确定后，才进行 QQ 接收、目标核对和少量发送验收。

本说明描述已实现的路径。具体构建、模拟器和测试结果以同包交付的 TEST-RESULTS 文件为准；编译成功不等于手机、真实模型或真实账号验收。
