# 想要的体验

主人的设定文档是私人的，不在仓库里。这里只留下判断标准：做任何改动前，先对照这六个场景想一想，她这样做自然吗、靠谱吗、烦人吗。

1. 单机 RPG：讨论、看着、临时接手；失败如实说，点击成功不等于游戏里做成了。
2. 自主群聊、按兴趣看视频，攒下想发的评论和想存的资料，由主人决定。
3. 跨日记忆，观点会变；来源可查，能看、能改、能忘、能删。
4. 后台任务和陪聊并行，借屏幕先商量；长按悬浮球五秒停下点击和输入。
5. 电脑离线照样在手机上聊，完全断网能翻本地日记；主人和自主活动的额度分开。
6. 普通的一天自然相处，不刻意把功能演一遍。

底线：仓库公开，不放隐私和密钥；主人私聊里的记忆不外传；外发评论和资料入库要主人确认；只认系统认证的主人。
