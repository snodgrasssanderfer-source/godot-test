# 本轮技术需求与验收方向

陪伴为主，agent 为辅助；移动端优先，保留 DSH 底座。以下是产品范围，不代表功能已经实现，也不授予开发测试真实账号操作权限。

## 陪伴与注意力
人格有稳定地基，同时允许有来源的兴趣、关系与习惯发展。普通语境交由模型理解，不把日常词句绑定为全局硬开关。主人注意力优先、可与社交并行；过载需协调。明确的限时免打扰应延后普通活动通知，风险通知遵循配置。文字为默认偏好，允许按情境选择语音；通道和语音目的地必须明确。

## 记忆与隐私
有意义经历可自主保存；事实、推断、偏好与来源分开，新事实优先且保留变化。尽量保留完整历史。忘掉抑制主动检索；删除清理正文、派生摘要、缓存、索引并阻止旧任务或恢复流程重引入。第一人称日记必须依据实际经历；缺失经历不能补编。用户可搜索、纠正日记、记忆、兴趣、待办。跨会话分享经过隐私判定的概要，不能开放原始私聊。朋友普通秘密与私人内容同等保护；只有主人可以要求修改人设和权限规则。

## 社交与行动
QQ 通过独立 NapCat / OneBot，使用稳定数字身份，支持分段多模态与明确失败反馈。朋友请求受预算和权限约束。低风险浏览、喜欢、关注及日常空间分享可配置自治；评论、加好友、加群、下载先汇总目标、动机和拟发内容，一次批准；拉黑、退群属于不同策略，可配置事后通知。不能代主人承诺。批准绑定准确账户、目标、内容、有效期；失败或未知提交不得盲目重试。真实账号行为仍未授权测试。

## 手机、声音与单机游戏
近期先悬浮球，完整 Live2D 后续；隐藏显示不应停止所有联系。感知主要随使用手机的会话运行，锁屏不要求全天监听。需要手机内播音频与麦克风的真实分轨输入；摄像头须主人明确提出并授权。自然语音、速度与打断为共同目标，半双工不得冒称全双工。说话人和情绪能力按实际准确度呈现。
输入控制服务于已授权手机单机 RPG 的观察、剧情、选择、探索和战斗，不扩展联机或独立游戏账号；首个适配游戏未选定。长按五秒停止点击/输入，保留聊天和观察，主人同意恢复。普通权限下无法承诺任意屏幕全局手势，须提供清楚的浮球/系统控制替代。

## 并行任务与连续性
后台任务应持久、可取消、可恢复，与陪聊并行；模型调用统一调度而不是几个 harness 争抢。文档、PDF、图片、素材、压缩和条件续接逐项实现并显示真实进度。能力安装或重大扩展先告知主人。普通事项自主处理；严肃任务范围不清时先确认流程。
手机有网而后台服务离线时，仍直接通过配置的 API 陪聊，恢复后同步；完全断网可读本地历史，不要求本地 LLM。跨设备最终共享经历，当前先落实手机和最小服务协议；不自动部署用户电脑。

## 预算、媒体与备份
活动和主人对话分账，原子预留覆盖并发、取消与未知最终费用。活动额度接近上限先提示，再停止收费活动，不降质量续费；主人预留也有上限。未知单价不得假称存在严格金额上限。普通媒体默认只保留经历，明确要求才长期留原图；素材包与临时缓存分开。备份端侧加密、可恢复，公开 Git 只能接受密文且密钥另存；本轮不上传真实用户数据。

## 验收与边界
覆盖实际 UI → 状态 → 动作链路；重点测试重复点击、取消/恢复、拒绝权限、断网、跨会话串线、删除代际、预算预留/未知费用、身份与批准绑定。单测/协议 fixture/浏览器/模拟器/真机分别记录。没有真机不能声称 Android 16 已验收；不再重复无 KVM 的系统首启消耗。
