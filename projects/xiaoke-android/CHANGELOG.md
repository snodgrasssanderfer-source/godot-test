# 更新说明

## 0.10.0（versionCode 11）
界面整个重做了，直接覆盖安装，数据都在。
- 修好了页面滑不动：内容超出屏幕的部分以前被直接裁掉，现在每一页都能正常上下滑。
- 底部五栏：聊天、生活、动态、连接、我的。模型和人设合进了「我的」。
- 聊天页像聊天软件：顶上是她的头像和状态，消息分日期，她在想时有打字动画；附资料和语音陪伴从底部弹出。
- 「动态」最上面就是等你放行的东西；其他设置都收进可展开的分组里。
- 字体换成霞鹜文楷，图标换了一套；暖色配色，浅色和深色都有（「我的 → 其他」里切换）。
- 各处的机械说明删掉了，文字改得短一些。
- 桌面图标、悬浮球和悬浮面板也换成了同一套颜色。

## 0.9.1（versionCode 10）
修复打开 App 就显示 “Companion plugin is not implemented on android”：本地数据库打开时一条设置语句用错了接口，数据库打不开，小克的模块整个没加载。直接覆盖安装 0.9.0，数据都在。
- 以后启动再出错，页面会显示具体原因，而不是这句英文。

## 0.9.0（versionCode 9）
直接覆盖安装 0.8.0（或 0.7.0），数据都在。瘦包，不带 Ubuntu 运行环境，沿用手机上已装的。

**B站**
- 扫码登录，之后自动续期，不用再粘 Cookie。打开“连接 → B站”点“扫码登录B站”。
- 她能按话题搜视频和专栏了：聊到的话题、她的兴趣，白天每天最多逛四次，不刷首页和热门。
- 看视频时会读弹幕和热门评论，也会读专栏；记下的经历写明实际看了哪些。
- 有人回复她的评论，她会知道，可以起草回复。所有评论、回复都先进待审清单。

**联网**
- 她能上网查资料、读网页。中转支不支持在第一次用时自动试出来；她自己逛兴趣时查的花活动额度。
- 请求结构改成利于 Gemini 缓存。额度页按金额记账时可填单价，命中缓存的部分按缓存价算，并显示缓存命中率。

**人设**
- 导入角色卡不再丢“历史后指令、深度提示、世界书”。
- 每轮在最近的消息旁放几句说话方式提醒，长对话不容易跑偏；悬浮窗、私聊、QQ 群都生效。

**QQ 空间**
- 她偶尔从群聊和自己的兴趣里找话题写说说（不用你们私聊的内容），先进待审清单；批准后在计划时段前后发，不会一点批准就发。
- 自己说说下有人评论，她会起草回复（进待审清单）；会看好友动态，点赞跟随“自主点赞”开关。

没在真机上跑过：扫码登录和续期、中转是否支持联网搜索、NapCat 的空间接口最需要实际试一下。

## 0.8.0（versionCode 8）
直接覆盖安装 0.7.0，数据都在（数据库会自动升级）。这一版是“瘦包”（约 32 MiB），不带 Ubuntu 运行环境：0.7.0 已经装好的同一版运行环境继续用。没装过 0.7.0 的话，先装 0.7.0 再装这个，或者让 App 从上游 Release 下载运行环境。

**记忆**
- 她按意思找记忆，不只按字面：今天说“周末吃什么”，她能想起几天前你说爱吃火锅。向量优先走中转的 Gemini 向量接口，中转不支持就自动用手机本地的小模型。
- 聊完停下 10 分钟，她会自己整理一遍：新的事、计划、她自己的看法，“昨天”“上周”都换成具体日期，并和以前的记忆连起来。
- 事情变了，旧的不删，标成“已过去”：她能说“你上周还说……”“我当时觉得……”。
- 新增“生活 → 档案”：她对你、群友、游戏、作品的简短印象，随聊天更新；群友档案只留在那个群里。

**QQ**
- 语音会先转成文字给她看。
- 群里多了一档：不想接话但有点在意时，她会点个表情。
- 私聊里她写回复时，你能看到“正在输入”。
- 她偶尔会戳一戳你；看过的消息会标为已读。

还没在真机上跑过；中转是否支持向量接口、语音转文字和表情回应最需要实际试一下。

## 0.7.0（versionCode 7）
直接覆盖安装 0.6.0，数据都在。

**底座**
- 同步上游 DSH 0.3.7：Android 16 + Shizuku 13.6.0 的闪退修复、副屏改进、后台保持、WebView 兼容、Harness 安装修复。运行环境换成 0.3.7 的 Ubuntu。
- 网络安全保持“只允许本机明文”，没有跟上游放开全局明文。

**聊天**
- 连发几条她会等你说完再回；@她时一秒内回。
- 她还在回的时候你又补了一句，会并进同一次回答。
- QQ 里较长的回复拆成几条、像打字一样隔一会儿发；悬浮窗和 App 里不拆。
- 群里说话多少可以在“连接 → QQ”里选（少一点 / 适中 / 多一点），她按群里实际节奏自动调。
- 她会按群学说话方式和黑话，在那个群和你们私聊里用。你的私聊从不拿来学。

**游戏**
- 装了 Shizuku：按住拖动（摇杆）、多指、长按都按真实时长，急停立刻抬手；截图更快。没有 Shizuku 照旧走无障碍。
- “你自己在后台玩”：游戏开到副屏里，你照常用手机。
- 她能把按钮存成标记直接找、直接点，把走通的操作存成路线，重放时每步核对画面，对不上就停下来自己看。
- 她的游戏心得写进记忆，在“生活 → 记忆”里能看能改。

还没在真机上跑过；Shizuku 注入、后台副屏和分段发送最需要实际试一下。
