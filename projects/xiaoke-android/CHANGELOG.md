## 0.13.0（versionCode 15）
小克接上 Claude。可以直接覆盖安装 0.12.0，数据都会保留。

**谁来回复**
- 你的私聊（App 里，和系统认证过的 QQ 私聊），以及你交代给她的事，都由 Claude 回复。走的是你自己用订阅登录的官方 Claude Code。
- QQ 群默认用 Gemini。在 连接 → QQ 里可以一个群一个群地打开 Claude。没打开的群，消息不会经过 Claude。
- 每条回复开始时就定好用哪个，所以一个群里不会一条 Claude、一条 Gemini 地来回换。改了设置，从下一条消息开始生效。
- 两边共用这个会话的记忆、档案，以及她在群里学到的说法。
- Claude 没登录、额度用完或者出错时，自动换成 Gemini，只通知你一次。额度恢复后（按 Claude Code 自己报的重置时间）会换回来。

**Claude Code**
- 装在 DSH 自带的 Ubuntu 里，是官方原版，没有改过。只从 downloads.claude.ai 下载：先用 Anthropic 的签名核对清单，再用清单里的 sha256 核对程序，对不上就删掉。下载断了能接着下，约 280 MB。
- 登录只走 Claude Code 自己的 `claude auth login`。App 只是把终端里的字传过去，不读、不存、也不转发账号和令牌。
- 在 我的 → Claude 里可以选模型和思考强度，看 5 小时和本周的订阅用量（只显示 Claude Code 自己报的数）。
- 她要改文件、跑命令时，会在聊天里、悬浮球上和通知里问你，你点允许才做；10 分钟没回就当作拒绝。群里根本没有这些工具。
- 她的记忆、日记、QQ、手机画面、B站、待审清单这些能力，通过一个只在本机的 MCP 服务交给 Claude。每轮回复有一个单独的令牌，只能用这一个会话自己的能力。

**代码工作区**
- 我的 → Claude → 代码工作区：把这个项目的仓库克隆到手机里。你在私聊里让她查 bug、改代码，她会开一个新分支、提交，再告诉你改了什么。推送要用你自己在终端里配好的 git 凭据。签名和发版还是在云端做，私钥不会放到手机上。

**首次引导**
- 新的顺序：运行环境和 Claude Code → 登录 Claude → 授权 Shizuku → Gemini → 额度 → 保活 → QQ。

## 0.12.0（versionCode 14）
按真机体检报告修。直接覆盖安装 0.11.1，数据都在。

**说真话**
- 看B站、读专栏、上网查、提醒这些后台的事，成功或失败都会告诉她（挂在发起的那个会话上），她也能自己查进度；没结果之前不会说看过。
- 你让她看的视频走你的额度。B站风控（-412 / v_voucher）会直接说“可能需要国内网络”。
- 换了模型也看得到自己调过哪些工具，不会再以为自己“忘了”。
- 提醒必须有时间（“2026-11-04 09:00”），到点才提醒；提醒内容不再写进日记。

**模型**
- 日常按你的设置用 argon。失败先同一模型再试一次，再换 flash，任务上记着每次尝试。
- 思考过程按标记过滤，漏进正文的自检段落会被去掉。
- 连接中断写清是什么错、等了几秒；30 秒没出字会显示“还在想”。

**连接**
- 打开 App 就把常驻服务和 QQ 连接拉起来。
- QQ 掉线（NapCat 心跳报不在线，或一分多钟没心跳）时，App 顶部和悬浮球都会提示。
- QQ 图片能看了（补上 multimedia.nt.qq.com.cn）；没读到的会写明原因。
- 现在的 NapCat 不支持读 QQ 空间，界面会标“需要升级 NapCat”，也不再每半小时空跑。

**需求**
- App 里和 QQ 私聊共用记忆和档案；日记、主动分享、“两小时没聊”都算上 QQ 私聊。
- 群里叫她别名也算（在“我的 → 人设 → 别名”里改）。
- 悬浮球默认右上角、贴边、记住位置；按住五秒急停改成震动提示，按住时球不会跟着动。
- 她自己点屏幕不会再被当成你接回操作。
- 你 QQ 私聊的回复不进草稿；旧草稿 3 天过期。
- 聊天后会记下兴趣，没兴趣时从群聊话题里找东西看。
- 首次引导加了“手机权限”一步，保存模型会实际试连一次。

**其他**
- 后台空闲耗电降下来（账本不再反复深拷贝，定时器从 5 秒改为 30 秒）。
- 人设版本不再无限重复，已有的重复会自动合并。
- “我的 → 其他 → 导出诊断日志”，key 和 token 会去掉。
- 回复里不会再出现 [图片附件] 这类占位符；“音乐”“快乐”不再触发笑哭表情；新版超级表情能认出名字。

## 0.11.1（versionCode 13）
直接覆盖安装 0.11.0，数据都在。
- **群里你跟她说话她就回**：叫她、引用她的消息、她刚说完你接着说、让她做事或问她问题，都直接回，不看回复频率，用你的额度。你 @ 或引用别人时，照常判断。
- **有人接她的话更容易被回**：她说完两分钟内有人接话，回复概率明显提高；引用她的消息对谁都算叫她。
- **表情发成真表情**：她写的 [表情:捂脸] 会发成 QQ 表情，认不出的标记直接删掉，不再以文字发出。
- **表情包**：在「动态 → 表情和素材」导入图片时选“给她当表情包用”。她联网时会每张看一眼、记一句描述（只看一次），聊天时按语境挑着发，发出去是图片。

## 0.11.0（versionCode 12）
直接覆盖安装，数据都在。
- **群里回复大量失败**：用你的中转实测，“函数调用 + 联网搜索”放在同一个请求里时，中转返回成功状态但内容是错误，旧版报成“协议错误”。现在联网搜索只单独请求，不再混着带。
- **失败自动降级重试**：去掉联网工具 → 换 flash → 不带工具。还是失败的话，任务卡片上写着每次尝试的 HTTP 状态、中转返回的原文、用的模型和工具，截图就能看。
- **她知道自己哪条没发出去**：哪个会话、什么时候、什么原因。问她时照实说，记录里没有的就说不知道。
- **主人私聊不再卡“发送中”**：直接发出，不走草稿。卡住的那条重启后会变成“待核对”。
- **让她去群里说话**：在私聊里说“去 xx 群说……”，她直接发到允许的群；不确定哪个群会列出来让你挑。
- **戳一戳**：群里和私聊的戳一戳她都能看到，知道谁戳了谁。
- **表情**：QQ 表情显示成 [表情:捂脸] 这样的名字。表情包和商城表情她会看一眼（花活动额度），同一张只看一次。
- 她不再主动谈自己的后台设置和模型配置，除非你私聊里问。
- 经历同步没开时不再攒待传队列。

## 0.9.0（versionCode 9）
直接覆盖安装 0.8.0（或 0.7.0），数据都在。瘦包，不带 Ubuntu 运行环境，沿用手机上已装的。

**B站**
- 扫码登录，之后自动续期，不用再粘 Cookie。打开“连接 → B站”点“扫码登录B站”。
- 她能按话题搜视频和专栏了：聊到的话题、她的兴趣，白天每天最多逛四次，不刷首页和热门。
- 看视频时会读弹幕和热门评论，也会读专栏；记下的经历写明实际看了哪些。
- 有人回复她的评论，她会知道，可以起草回复。所有评论、回复都先进待审清单。

**联网**
- 她能上网查资料、读网页。中转支不支持在第一次用时自动试出来；她自己逛兴趣时查的花活动额度。
- 请求结构改成利于 Gemini 缓存。额度页按金额记账时可填单价，命中缓存的部分按缓存价算，并显示缓存命中率。

**人设**
- 导入角色卡不再丢“历史后指令、深度提示、世界书”。
- 每轮在最近的消息旁放几句说话方式提醒，长对话不容易跑偏；悬浮窗、私聊、QQ 群都生效。

**QQ 空间**
- 她偶尔从群聊和自己的兴趣里找话题写说说（不用你们私聊的内容），先进待审清单；批准后在计划时段前后发，不会一点批准就发。
- 自己说说下有人评论，她会起草回复（进待审清单）；会看好友动态，点赞跟随“自主点赞”开关。

没在真机上跑过：扫码登录和续期、中转是否支持联网搜索、NapCat 的空间接口最需要实际试一下。

## 0.8.0（versionCode 8）
直接覆盖安装 0.7.0，数据都在（数据库会自动升级）。这一版是“瘦包”（约 32 MiB），不带 Ubuntu 运行环境：0.7.0 已经装好的同一版运行环境继续用。没装过 0.7.0 的话，先装 0.7.0 再装这个，或者让 App 从上游 Release 下载运行环境。

**记忆**
- 她按意思找记忆，不只按字面：今天说“周末吃什么”，她能想起几天前你说爱吃火锅。向量优先走中转的 Gemini 向量接口，中转不支持就自动用手机本地的小模型。
- 聊完停下 10 分钟，她会自己整理一遍：新的事、计划、她自己的看法，“昨天”“上周”都换成具体日期，并和以前的记忆连起来。
- 事情变了，旧的不删，标成“已过去”：她能说“你上周还说……”“我当时觉得……”。
- 新增“生活 → 档案”：她对你、群友、游戏、作品的简短印象，随聊天更新；群友档案只留在那个群里。

**QQ**
- 语音会先转成文字给她看。
- 群里多了一档：不想接话但有点在意时，她会点个表情。
- 私聊里她写回复时，你能看到“正在输入”。
- 她偶尔会戳一戳你；看过的消息会标为已读。

还没在真机上跑过；中转是否支持向量接口、语音转文字和表情回应最需要实际试一下。
