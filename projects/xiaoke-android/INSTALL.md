# 小克安装说明（0.3.0 起）

## 旧版怎么处理（只需做一次）
从 0.3.0 起，安装包统一使用小克的固定签名（证书 SHA-256 `398ee6d9…609da1c2`），以后的新版本都能直接覆盖安装，记忆和日记会保留。

之前手机上装的版本签名不同，包括旧参考包 0.2.0（证书 `0253853d…`）和此前用临时 debug 签名打的测试包。它们不能被新版覆盖，必须先卸载一次，卸载会清掉旧版里的数据。

1. 如果旧版的「生活 → 备份」里有导出功能：先设一个至少 8 位的密码，导出加密备份文件，保存到手机存储里。
2. 卸载旧版。
3. 安装新版，到「生活 → 备份」用同一个密码导入。旧版备份格式是否兼容没有验证过；如果导入失败，旧数据就只能放弃。

## 第一次安装
- 在系统设置里允许用文件管理器或浏览器「安装未知应用」。系统或 Play Protect 提示风险时，选择仍然安装。
- 包约 312 MiB，内置 Ubuntu 运行环境，首次启动解包会比较慢。
- 以后安装新版时直接覆盖，**不要先卸载**，否则数据会丢。

## 权限（按需开启）
| 权限 | 用途 | 位置 |
|---|---|---|
| 通知 | 常驻通知、提醒 | 首次启动时允许，或在 App「权限与运行状态」里开启 |
| 悬浮窗 | 悬浮球、五秒急停、待审角标 | App 内「设置」按钮跳转 |
| 无障碍（小克/DSH） | 看画面、代操作游戏、UI 提交 | 系统设置 → 无障碍；还要在 App 内授权具体目标应用 |
| 麦克风 | 语音陪聊、有界收音 | 用到时系统会询问 |
| 屏幕录制（每次） | 收听其他应用的声音 | 每次开始收音时系统会询问，只对本次有效 |
| 通知使用权 | 备用 QQ 通知路线（非 NapCat 时） | 系统设置 → 通知使用权 |
| 电池优化：不限制 | 后台常驻不被系统回收 | 系统设置 → 应用 → 电池 |
| 自启动（部分国产系统） | 重启后恢复后台 | 手机管家 / 应用启动管理 |

## 让她在后台和重启后也能找你
在 App 设置里打开「后台常驻」。打开后会有一条常驻通知，App 被系统回收后也会由常驻服务拉起；手机重启后，第一次解锁时自动恢复。解锁后主动找你、夜间安静、群聊和 B站自主活动都依赖它。

## 首次配置
在 App 里填写中转地址和密钥、开启联网，在「生活 → 额度」分别设好主人和活动两个额度。没有设置额度时，所有模型请求都会被拒绝。
