Greyfog (working title) - 测试包
====================================================

【现在一进游戏是新街区的第一块：街角的北线加油站】
你站在加油棚下的警车旁。这是按新方向手工做的第一个空间：便利店、员工室、库房、
后巷、门前的一段街。街对面和街角那两栋还只是黑色的占位体，走不进去。
想请你看的：
  - 像不像一个真地方？室内还显不显得小、矮、挤？
  - 雾够不够浓（- 和 = 可以调淡 / 调浓，按 F2 看当前倍数，告诉我们哪个数顺眼）
  - 从车道走上人行道、进店门、进员工室、出后门到后巷，哪里卡脚
  - 帧率（F2 左上角）
按键：F2 数字  F3 去靶场（再按回来）  F5 回到警车旁  P 通电 / 停电  V 体积雾开关  F10 退出
这里没有怪，没有可以拿的东西，门都是敞开的。

【下面是靶场的说明（按 F3 进）】

双击 Greyfog.exe 运行。这是一条灰盒街道上的靶场，用来试移动和枪械手感、
测帧率。街上的 7 个人形是靶子，打倒后几秒会自己站起来。
每盏路灯的灯杆旁有两台旧电视，它们是第一种怪物：平时不动，枪开多了会醒（见下面"怪物"）。
备弹无限。所有音效都是合成的占位音。

想请你做两件事
  1. 按 B 跑基准测试（约 2 分钟，期间不要动鼠标键盘）。跑完屏幕中间会显示
     一张表，拍张照发给我们就行。同样的内容也存在：
     %APPDATA%\Godot\app_userdata\Greyfog (working title)\benchmark.txt
  2. 随便玩几分钟，告诉我们哪里手感不对：移动快慢、滑铲、翻越、
     后坐力、开镜速度、换弹节奏、霰弹枪的泵动、钢管的挥击。

操作
  WASD        移动              Shift       冲刺
  Ctrl / C    蹲（冲刺时按：滑铲）  空格        跳；对着矮墙、栅栏、车：攀爬或翻越
  Q / E       左右探头           F           手电
  鼠标左键    开火 / 挥击         鼠标右键    开镜
  R           换弹              1 2 3 / 滚轮  手枪 / 霰弹枪 / 钢管

调试
  [ ]   时间减 / 加半小时       T     时间流动 / 冻结
  P     街区通电 / 停电          G     全局光照 SDFGI 开 / 关
  V     体积雾 开 / 关           B     基准测试
  - =   鼠标灵敏度 降 / 升（左上角显示百分比）
  F1    按键提示                F2    左上角数字
  F3    回到新街区（加油站）
  F5    回到出生点              F11   全屏 / 窗口
  Esc   释放鼠标                F10   退出

负伤（没有血条，靠画面和手感判断自己的状态）
  F6    打伤一条腿              F7    打伤辅助臂（左）
  F8    打伤持枪臂（右）        F9    打伤躯干
  J     用胶带包扎流血最重的伤口  K     吃止痛药（20 秒后起效）
  H     全部治好
  同一个键多按几次，伤会从轻到重再到废。可以试试：腿伤后冲刺变慢、重伤不能冲刺和滑铲；
  辅助臂受伤后换弹和泵动变慢；持枪臂受伤后准星晃、开镜慢、后坐力大；
  流血不包扎，画面会慢慢褪色、四周变暗，血流光就倒地（5 秒后回到出生点）。

怪物（第一种：旧电视）
  平时是人行道上的一件旧家电。你在它附近开枪，那一段电网的"惊扰值"上涨（左上角 grid 那一行的四个数）：
  到 35 屏幕亮起雪花；到 70 第一台站起来，80 第二台。醒了以后它先走向最近听到的声音，
  看见你就追，冲到 3 米左右会后蹲、屏幕闪白半秒，然后扑过来。那半秒就是让你躲的。
  外壳很硬（子弹只有三成伤害，会冒火花）；先打碎屏幕玻璃，再往屏幕里打才是弱点。
  手枪瞄着屏幕 3 发能打死，乱打外壳要 11 发。被它扑中会受伤流血。
  N     给你所在的这一段电网直接加 25 惊扰值（不想开很多枪时用）
  M     把怪物全部收走 / 放回来（只想练枪时按一下）
  想听听意见：它醒得太早还是太晚？速度、前摇的半秒够不够反应？打起来有没有"外壳硬、里面软"的感觉？

左上角：帧率、帧时间、最近两秒里最慢的一帧；时间和画质开关；移动速度；
刚才那个动作的噪音半径（米）；电网四个节点的惊扰值和"醒着的 / 还活着的"怪物数；最后一行是伤情
（H 头、T 躯干、Ar 持枪臂、Al 辅助臂、Ll Lr 两条腿的机能，以及血量、流血速度、疼痛、伤口数）。
正式游戏里这些数字都不会显示。

画面固定按 1920x1080 渲染再缩放到你的屏幕，所以帧率数字不受显示器分辨率影响。
垂直同步是关的，帧率不封顶。
