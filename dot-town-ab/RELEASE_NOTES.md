# 小镇试作：两个独立同题版本

主题来自现有《像素小镇》的玩法概念，两版从零实现，没有复用 Claude 或上一轮游戏的代码、美术。

## 下载与操作
- **town-trial-1.apk**：手机桌面名称 小镇试作 1。
- **town-trial-2.apk**：手机桌面名称 小镇试作 2。
- 两个包名不同，可同时安装。均为 ARM64、Android 7.0+、横屏触控测试版。
- 左侧摇杆移动，右侧拖动看向，瞄准近处目标后点交互；暂停菜单可调节和重新开始。
- 翻土、播种、浇水，经过三个浇水后的清晨成熟；收获放入出货箱，翌日每份结算 40 金币；屋内床可以睡到次日并保存。

## 比较方法与验收边界
两组均按 GPT-6.1 Sol / xhigh 配置，使用相同任务范围、MCP 工具和 45 分钟首轮制作目标；一个使用待测工作流 Skill，另一个不读取它们。发布页暂不标注对应关系，避免影响第一印象。两组均保留同一主动解题基础要求。新上下文不继承之前作品，但共用主机且可见 Skill 目录说明，因此这是一次实用对照，不是严格因果实验或统计结论。

两版均完成桌面 Godot 运行时的移动/碰撞、种田三日循环、不浇水不生长、出货结算、居民按日对话、昼夜、暂停、重开确认、存档进程重载和多指触摸注入测试。状态设置和时钟加速用于测试准备，不冒充真人完整游玩。Android 导出、签名及包结构经过检查；尚未在真实 Android 设备安装运行，也未验证手机帧率或实际音效。
