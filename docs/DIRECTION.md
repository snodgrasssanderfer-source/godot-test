# 方向说明：《凌晨三点公路镇》改成箱庭（2026-11-12 定）

这份文件取代 GDD 第六节的地图部分，以及 `docs/blender_town_workflow.md` 里所有"按灰盒占地换模型"的约定。
GDD 的故事、怪物、武器、钥匙链不变。

## 一、为什么改

旧做法从"僵毁式开放城镇"出发：250 × 250 米、按市政逻辑铺一整条街、用代码（`fps/world/town/town_layout.gd`）批量生成房子，Blender 模型守着灰盒的占地。
结果是用户实测的样子：

- 街上零星几栋房子，间距均匀，门窗位置一样，一眼能看出是同一个模板
- 250 米只弯了 13 米，雾的浓度 0.011，一眼望到头
- 室内按真实尺寸 2.7 米层高做，游戏里显得又小又挤又矮
- 人行道是一段段转了角度的盒子，接缝成锯齿，车道口多一级台阶，走过去会卡脚
- 贴图质量很好，但贴在平板方盒子上，显得像一张墙纸

**问题出在方向，不在 AI 的能力，也不在素材。**目标是恐惧之泣式的沉浸感：玩家通关时才想起"这只是个游戏"。
这要靠一个个手工设计的空间，而不是一座生成出来的镇。

## 三、箱庭是什么样

**一个街区，不是一座镇。**约 120 × 80 米。几栋楼背靠背挨着，后巷、院子、篱笆缺口把它们串成环。

- **能进的只有四处**：加油站和便利店、米勒五金与汽修行、锈锚酒馆和洗衣房、克拉克家。
- **其余的是手工做的背景**：层层叠叠的屋顶轮廓、某扇亮着的窗、停着的车，玩家永远走不到。不用代码批量生成，哪怕只做外立面也要一栋一栋做。
- **外圈封死**：北面匝道被浓雾吞掉，南面翻倒的运木半挂车，侧面铁丝网、深沟、密林。
- **回环和捷径**：每个区域至少两个出入口。从里面打开的后门、院门变成回头的捷径，越到后期跑图越短。
- **地标**：加油站的高杆价格牌和灯棚，在街区大部分地方从屋顶上方都看得见，玩家永远知道"家"在哪边。

### 钥匙链（GDD 原有，就是箱庭的骨架）

```
加油站（起点）
 └ 员工室：纸质地图 + 后备箱钥匙 → 后备箱：霰弹枪
 └ 后巷：水管，第一战（售货机 / 冰柜怪教学）
米勒五金：前店能进，库房锁着
 └ 酒馆 / 洗衣房：Lou 身上的库房备用钥匙
米勒五金库房 → 地沟：发电机皮带 + 千斤顶（拟态红色工具箱怪）
克拉克家：二楼衣帽间枪柜，冲锋枪 + 车库钥匙
 └ 车库：满电蓄电池（卷帘门巨响，唤醒巢穴和整条街的路灯怪）
抱着电瓶回加油站 → 修车 → 结尾无线电
```

**第一步不是建模，而是把这条链画成平面草图**：标出每个区域、回环、捷径门、地标视线、怪的位置。用户在手机上看一张图点头之后再动手。

## 四、每个空间怎么做

1. **一个空间一个 Blender 脚本，手工设计**。不用循环批量生成房子、窗户、货架。随机只用于小杂物的散布，而且只撒在手工指定的范围里。
2. **先写三行再建模**：
   - 这里原来是做什么的（日常）
   - 半小时前发生了什么（中断的痕迹）
   - 玩家在这里要做什么（拿什么、打什么、从哪出去）
3. **从大到小**：大形体 → 中等物件 → 小杂物 → 污渍。大形体不对，小东西救不回来。
4. **九成日常，一成异常**。玩家得先认出"这就是个普通的加油站"，不对劲的东西才显得不对劲。
5. **轮廓比贴图重要**：屋檐出挑、门框窗框的凹凸、踢脚线、雨水管、台阶出沿、墙有厚度、边缘倒角。不允许出现单块平板的墙。
6. **模型自带碰撞**：可见网格生成碰撞，复杂物件配 `-colonly` 简化碰撞体，草和电线用 `-nocol`。
7. **光用来指路**：冷光给安全的日常，暖光给后巷和住家，异常的东西自己发光。要找的东西附近必须有光够得着。
8. **留白**：一面空墙挨着一个密集的角落，比处处均匀地摆要好。

## 五、尺寸

真实尺寸在第一人称里会显得压抑，所以统一放大：

| 项目 | 新标准 |
| --- | --- |
| 住宅层高 | 3.0 到 3.2 米（原 2.7） |
| 店铺层高 | 4 米左右 |
| 房间平面 | 按真实尺寸放大到 1.3 倍左右 |
| 门洞 | 净宽 1.1 到 1.2 米，净高 2.2 米以上 |
| 走廊 | 至少 1.6 米宽 |
| 室外视线 | 每 25 到 40 米被挡一次：真正的弯道、车、围挡、建筑转角 |
| 雾 | 浓度调到大约 25 到 40 米外就看不清（现在的 0.011 太淡，100 米外还能看见三成） |
| 路缘 | 看得见的路缘照常做，碰撞用一条连续、不可见的小斜坡，不用一级台阶 |

"不能动的尺寸"那张表（`docs/blender_town_workflow.md`）是**下限**，仍然要守。

## 六、贴图怎么用才不显平

素材质量够好，问题都出在用法上：

- **每个面都要有颜色、法线、粗糙度三层**。库里只有颜色图的，先生成法线和粗糙度再用，不能只贴颜色。
- **像素密度统一**：视线高度的墙面大约每米 512 像素（一张 1024 的图铺 2 米）。离得远的面可以放宽。
- **打断平铺**：墙面用踢脚、腰线、转角条分段；同一面墙混用两三种变体；墙根贴脏、窗下贴流痕、角落贴霉。
- **脏分四层**：整面的旧 → 大片的渍 → 局部的损 → 人留下的痕迹。污渍要有来由：锈从支架往下流，油渍在停车的位置，霉在墙根。
- **先用现成的**：77 个模型和已装好的材质先用上，缺了再出新图。新贴图暂停，直到第一个空间做完、用户试玩过。

## 七、做事的顺序

1. **清理**：交接文档归档（见 `CLAUDE.md`），游戏入口从靶场改到新街区，靶场留着调枪。
2. **平面草图**：钥匙链加平面布局，出一张图给用户确认。
3. **第一个空间：加油站地块**，连同门前的一段街和后巷，完全按本文件的规则从头做。
4. **打包给用户在电脑上走**。用户的反馈决定后面的规则要不要改。
5. 按钥匙链的顺序做下一个：米勒五金 → 酒馆和洗衣房 → 克拉克家 → 背景楼和外圈。

**第一个里程碑的标准**：用户从出生点走进便利店、员工室、后巷，觉得"这不像是在玩游戏"。没达到这个标准，就不往下一栋做。
