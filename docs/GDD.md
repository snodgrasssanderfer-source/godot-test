# 《未命名：凌晨三点公路镇》商业 Demo 游戏设计总稿（GDD）

## 一、 核心定位与三大支柱
一款融合了 **《使命召唤（COD）》顶级写实枪械与机动手感**、**《僵尸毁灭工程（Project Zomboid）》硬核拟真修车搜刮与市政生态**、以及 **《恐惧之泣（Cry of Fear）》实拍脏贴图美学与阈限空间压迫感** 的第一人称生存恐怖游戏。

- **核心反差卖点**：玩家扮演一名受过专业训练、拥有现代警用战术动作的正常巡警，用最硬核利落的现代枪械物理，去轰击最荒诞、最掉san的“日常家电/市政设施活体怪物”；为了逃离死寂小镇，不得不把怪物的血肉器官绑上自己的制式警械。
- **核心体验准则**：拒绝“机械的游戏关卡与掩体味”。按真实市政逻辑建镇，剥离一切显性游戏 HUD，让玩家沉浸在凌晨三点的冷雨死寂中，玩到一半手心冒汗时才猛然想起“还好这只是个游戏”。

## 二、 硬件基准与美术渲染管线（开发环境：RTX 5060）
- **开发与目标算力基准**：NVIDIA RTX 5060（主流甜点卡，兼顾高帧率射击手感与现代光影氛围）。
- **算力分配策略（《恐惧之泣》实拍美学 × 现代光影物理）**：
  1. **省显存、高真实度的场景基底**：借鉴《恐惧之泣》“不靠堆砌几千万面高模、而靠实拍脏贴图与生活杂物密度造就极致真实”的思路。建筑与街道采用中低面数结构 + 高信息密度实拍旧化贴图（水渍、锈迹、油污、剥落墙皮），严格控制显存占用，杜绝无意义的算力浪费。
  2. **算力全砸向“手感”与“氛围”**：将 RTX 5060 省下的性能全部投入到三个核心体验点——
     - **120 FPS+ 满帧丝滑的第一人称枪械动画与战术机动**（保证 COD 级别的快拔、检视、滑铲响应）；
     - **雨夜动态光影与体积雾**（柏油路薄积水对霓虹灯、警车大灯、频闪水银路灯的实时反射与丁达尔体积雾）；
     - **局部高密度受击物理反馈**（霰弹枪轰碎家电外壳时的金属变形、玻璃飞溅与内部血肉组织飙射）。

## 三、 故事背景与起承转合（商业 Demo 闭环）
- **主角设定（纯粹的倒霉路过）**：没有苦大仇深的宿命论或心理包袱。主角只是一名刚下夜班、纯粹路过的普通警察，主打“正常人与异常世界瞬间断裂”的真实惊悚。
- **开局前 3 分钟（主播切片与入戏钩子）**：
  1. 凌晨 3 点，主角开警车在高速上刚跟同事通完电话闲聊，因没油拐进镇口的 24 小时自助加油站。
  2. 加油站惨白的灯管嗡嗡作响，空无一人。主角下车绕着便利店找人，低头看时手机屏幕闪了两下彻底黑屏死机。
  3. 回到车上拧钥匙，发动机彻底抛锚。来时的匝道被浓得发黑的雾气吞没，主角被迫拿起手电筒走进这座半小时前刚停摆的诡异空城，搜集【发电机皮带】【千斤顶】【满电蓄电池】修车逃生。
- **最后 30 秒结尾钩子（Steam 愿望单转化器）**：
  玩家九死一生凑齐零件、打退终局怪潮，钻进驾驶座拧动钥匙——引擎轰鸣启动，车灯切开浓雾冲上高速匝道。正当玩家长舒一口气以为逃出生天时，车载警用无线电突然滋啦响起，传出了开局那位同事的声音，但同事正像卡带的录音机一样，机械、阴冷地一字不差重复着开局那通电话的台词；与此同时，中控台仪表盘的缝隙里，缓缓渗出了暗红色的粘稠黑油……画面骤然切黑，弹出游戏标题。

## 四、 怪物设定与“尸检式”生态叙事
- **核心威胁源（非丧尸）**：镇上老旧笨重的**日常家用电器与市政设施扭曲成的活物**（CRT大屁股电视、双开门老冰箱、滚筒洗衣机、自动售货机、铸铁消防栓、路灯杆）。
- **铁皮包着镇民的肉（核心掉san设定）**：
  怪物外层是金属、塑料与玻璃，内里却长着活体肌肉、脊柱与呼吸感，像野兽一样弓背扑咬。**家电里面的血肉，就是失踪镇民的残留痕迹**——玩家拆解怪物尸体搜刮改装素材或零件时，如同进行一场诡异的尸检，会从收音机或微波炉的肉腔里翻出刻着名字的结婚戒指、带手表的断腕。
- **90% 明牌违和怪 + 10% 纯正拟态猎手**：
  - **大部分怪直接出现**：远远就能看见，处于“看着像日常物品但比例歪斜、抽动帧率诡异”的状态，保证玩家能痛快施展 COD 的拉枪线、滑铲与正面交火。
  - **极少数纯拟态猎手**：平时与真实环境 100% 吻合，作为搜刮时的心理暗雷。但必留符合刑侦常识的**细微破绽**（如停电街区里独自亮微光的售货机、雨夜里顶盖干燥冒白气的垃圾桶、没有水泥接缝的消防栓、极轻微的铁皮喘息声）。
- **活物生态与环境叙事（非战斗状态）**：
  - **趋光与筑巢**：整栋民宅的小家电拖着肉筋电线爬上二楼卧室，围着一台像心脏一样搏动发紫光的大冰箱喘气。
  - **模仿生前惯性**：半夜自己推着自己在人行道上走的婴儿车；每隔五分钟自己摘下又砸回听筒的公用电话亭。
  - **食物链捕食**：巨型铸铁消防栓在暗巷里按住小型收音机怪撕咬吸食黑油，玩家可引怪互咬、趁乱摸物资。

## 五、 Demo 武器库与“活体枪匠”系统（4主1副）
不盲目堆砌枪械数量，围绕巡警最合理的初始装备，结合【外层金属破甲 + 内层血肉弱点】的受击反馈，每把武器提供 **1个五金店常规改件 + 1个掉san活体器官改件**（以加油站警车引擎盖作为改装台）：

1. **Glock 19 警用手枪（已制作）**：高机动快拔点射。
   - 常规改件：【机油滤芯消音器】（挡机瞄视线，打几发后炸裂报废）。
   - 异变改件：【路灯怪的趋光眼】（绝缘胶带绑在导轨下，充当惨白手电筒；开镜瞄准时眼球自动转向锁定怪物铁皮下的肉核弱点）。
2. **雷明顿 870 泵动霰弹枪（已制作）**：开局撬开警车后备箱获取。可切换鹿弹（喷软肉）、独头弹（破厚铁皮）、破门橡胶弹（强击退保命）。
   - 常规改件：【锯短枪管 + 鸭嘴收束器】（横向一字散布，狭窄走廊清场）。
   - 异变改件：【高压电线怪的神经束】（缠绕护木与枪机，肌肉收缩带动极速上膛，弹丸附带滚烫黑油腐蚀铁壳）。
3. **警用 MP5 或 民用 AR-15（新增，中后期获取）**：纯粹的 COD 战术冲刺、滑铲泼水爽感担当。
   - 常规改件：【蓝胶带双联弹匣】（实现秒换弹）。
   - 异变改件：【收音机怪的发声腔】（塞在枪托连接处，开火伴随镇民惨叫与高频无线电杂音冲击，令周围同类怪物出现短暂掉帧硬直）。
4. **生锈水管（已制作）→ 消防破门锤（进阶）**：近战与物理交互（砸锁、撬门、剖开家电外壳）合一。
   - 异变改件：【冰箱压缩机 + 咬合齿】（长按重击时管内肉筋如液压锤暴起，一击砸扁重型家电铁壳）。
5. **战术副武器：警用泰瑟电击枪（新增，独立快捷键）**：
   - 左手速射控制技。电击电器怪使其短路冒烟硬直 3 秒，或直接把纯拟态怪从伪装中电出原形。
- **动态检视（Inspect）叙事**：前期按检视是帅气的警用战术验枪；后期改装异变器官后，检视动作变成面无表情地弹掉枪管上的肉芽、拍打枪身上躁动的呼吸囊。

## 六、 Demo 地图地编规划（250米 × 250米 箱庭）
- **地域与历史层叠**：北美五大湖铁锈带或太平洋西北岸的阴雨老国道旁。70年代红砖木结构底子 + 80年代发霉碎花墙纸 + 90年代笨重老旧家电 + 2000年代明装乱拉电线。
- **街道与无缝衔接**：微弯弧形单车道（配合浓雾自然阻断远景视线、节省渲染开销），头顶密集木电线杆与闪烁路灯（藏匿路灯怪），北端浓雾封路、南端运木半挂车翻车自然封路。所有一楼门窗全通透真玻璃，支持开门、撬后门、砸窗战术翻越三种进屋动线。
- **四大核心建筑布局**：
  1. **76号自助加油站 & 快客便利店（起点/安全屋）**：加油棚下停着警车（车灯为全图安全光源锚点，引擎盖为改装台）。含便利店货架、滴水冷柜、冒热气的咖啡壶、后间员工室（拿手绘宣传单纸质地图与后备箱钥匙）及后巷垃圾站（拿水管，触发第一只售货机/冰柜怪教学战）。
  2. **米勒父子五金与汽修行（街对面，前店后厂）**：前店高耸五金货架视线极窄（小型电钻/风扇怪从顶上扑击）；后厂车间带 **1.5米深积油修车地沟**（跳入地沟摸【发电机皮带】与【千斤顶】，地沟暗处藏纯拟态红色工具箱怪）；带二楼半开放账房阁楼，可高低差射击或翻窗上遮雨棚。
  3. **锈锚小酒馆 & 24小时投币洗衣房（街角联排红砖房）**：洗衣房内十几台滚筒洗衣机半夜震动空转，玻璃窗内翻滚着带戒指手表的尸块，真怪混在其中；隔壁小酒馆为U型吧台与卡座环形CQB场地（拿汽修店库房备用钥匙）。
  4. **克拉克家独栋民宅（街道最深处，终局高潮）**：一楼保持生活突然中断感（电视闪雪花、桌上剩饭），但地面满是家电爬行的拖拽刮痕直通二楼；二楼卧室为家电巢穴（围着搏动大冰箱喘气），衣帽间枪柜拿【MP5/AR-15】与车库钥匙；拉起侧面车库卷帘门拿【满电蓄电池】时，巨响惊醒二楼巢穴与整条街路灯怪，触发抱电瓶单手射击杀回加油站的终局跑酷战。

## 七、 待 PC 端小克继续深化与落地的任务清单
1. **无 UI 状态与部位负伤设计**：在剥离传统血条的前提下，设计《僵毁》式的部位负伤（手伤影响 COD 换弹速度、腿伤锁死滑铲冲刺、失血视觉与袖口滴血）与便利店/酒馆日常医疗品（工业胶带、威士忌、止痛药）的具体数值与状态机。
2. **实体化背包与大件搬运规则**：设计警用战术腰带与后备箱勤务包（蹲下拉开拉链整理）的交互逻辑，以及左手抱起【蓄电池】等大件时强制切单手手枪的具体惩罚与快速丢弃/拾取手感。
3. **低头修车的“视野剥夺”交互**：设计将零件装回警车时的第一人称探头进引擎盖实操机制（拧螺母、套皮带、接电瓶夹），如何利用引擎盖遮挡视野与背后浓雾异响制造最高潮的心理压迫。
4. **枪声与“电网惊扰”生态算法**：量化开火噪音对街区电力的共振机制（开枪越多，沿街民宅电视雪花屏亮起越多、休眠家电苏醒越多），平衡 COD 爽快开火与生存压力。
5. **【资产清单】列出《恐惧之泣》风格实拍脏贴图搜集清单**：根据上述 4 栋建筑、老家电与铁锈带雨夜街道设定，列出一份详细的贴图材质需求清单（墙皮、地面、旧家电表面、污渍、招牌等），供后续搜集与制作。
