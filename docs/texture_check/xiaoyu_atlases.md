核对日期 2026-11-12。对象是分支 `xiaoyu/atlases-20261111` 的 `textures_xiaoyu/`（**不在 `main` 上**，是从 `main` 开出的单独分支，

## 结论

**气氛和内容都对路，比之前两批素材好得多**：名字和图基本对得上，年代感、脏旧感、"铁皮包着肉"的怪物内腔都是设计稿要的东西。
但它们是**设定图 / 素材拼板**，不是能直接贴到模型上的贴图，接入前有几件事必须处理。

| 问题 | 涉及 | 要怎么办 |
| --- | --- | --- |
| **真实品牌** | #6 售货机上是可口可乐、雪碧、七喜、百事的商标 | 不能用。这一块要重画成虚构品牌（用户已定全部用虚构商标） |
| **像真人的人脸** | #22 牛奶盒寻人、#24 全家福、#25 驾照、#26 寻人启事和报纸、#33 杂志封面 | 是生成的脸，不是照片，但清单的规矩是不用真人脸。建议换成剪影、涂黑或明显的插画风 |
| **像真实产品的外形** | #32 游戏机很像世嘉和任天堂的机型；#18 手枪、电击枪，#9 警车，#27 冲锋枪都接近真实型号 | 只当参考，建模时要改成原创外形 |

| **立体物件画成了效果图** | 千斤顶、电视、冰柜、警车、枪等，是带光影的渲染图或"假展开图" | 贴不到模型上，只能当建模和画贴图的参考 |

| **只有颜色图** | 没有法线和粗糙度 | 平面的东西可以从颜色图推一版；规范对图集本来也只要求颜色图 |

## 覆盖了清单的多少

清单里"画"类共 323 项。按文件名统计，这 34 张提到了其中 296 项（P0 107 / 120，P1 135 / 149，P2 54 / 54）。
P1 和 P2 的文件名写的是编号范围，这个数是按范围推出来的；**一张图里是不是真的每一项都画了，没有逐项核对**。

## 和交付规范的出入

`docs/texture_delivery.md` 要求单独分支（做到了）、一张图对应一项、按规定命名、带来源记录。这批图是多项拼在一张里、保留了原始文件名。
作为初稿存放没有问题；真正接入时由做工程的人把用得上的格子裁出来，按规范命名后放进 `fps/assets/textures/`。

这批图是生成工具做的，按清单的规矩要记录，Steam 上架时要申报。
